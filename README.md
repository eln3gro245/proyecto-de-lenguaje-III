# The Hero Knight - Pre-Alpha

Bienvenido a la version Pre-Alpha de **The Hero Knight**

El proyecto se encuentra en una etapa temprana de desarrollo, lo que quiere decir que el juego aunque se ejecute igual presenta ciertos detalles en cuanto al escenario e inteligencia de los enemigos.

## ¿De qué trata el juego?

**The Hero Knight** es un juego de fantasia oscura donde asumes el rol de un caballero para explorar un castillo y vencer a un jefe.

### 🛠️ Estado Actual (Qué puedes probar)

En esta versión pre-alfa se puede jugar/probar:

- [x] Movimiento básico del personaje y salto.
- [x] El primer nivel.
- [x] Sistema de movimiento básico.

### Errores Conocidos

Actualmente existen los siguientes problemas:

- Ea camara no sigue al protagonista, si el caballero se cae la camara no lo sigue se queda fija en el punto exacto donde salto el caballero
- El tema sonoro se reprofuce en segundo plano sin parar, por ejemplo empieza: normal, termina, empieza otra vez y luego se escucha en segundo plano.

### Cómo jugar

1. Para ejecutar el juego ve al archivo app.py, pulda Ctrl+Mayus+Ñ y escribes en la terminal python app.py
